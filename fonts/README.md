# Fonts

All fonts here are under the SIL Open Font License 1.1 (full text in `OFL.txt`). They're served
from this folder, not from Google Fonts, so the app looks right offline.

- `bodoni-moda-*.woff2`: Bodoni Moda. Copyright 2020 The Bodoni Moda Project Authors.
- `anton-400.woff2`: Anton. Copyright 2020 The Anton Project Authors.
- `space-mono-*.woff2`: Space Mono. Copyright 2016 The Space Mono Project Authors.
- `weekdays-jp.woff2`: only the weekday kanji (日月火水木金土曜) from Noto Serif JP. Copyright 2017 Adobe.
